# HiResume (ResumeAI) App 🚀

Next.js 16 web application for **HiResume** — the AI-Powered ATS Resume Optimizer & Smart Tailoring Engine.

Engineered by **[Divyansh Sharma](https://github.com/divyanshsharma24-git)** · *Department of Artificial Intelligence and Data Science Engineering (AIDE), IIT Jodhpur*.

For complete documentation, visual tour, and architecture breakdown, see the [Root README.md](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Copy env example and add your Gemini API Key
cp .env.example .env.local

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
